# Hermes Turbo Agent

مهارة توصيات وتدقيق أداء لـ Hermes Agent. لا تنشئ نسخة fork تنفيذية؛ بل تقيس الاختناقات وتطبق تحسينات صغيرة قابلة للاختبار والتراجع.

## التوصيات

- `orjson`: تسريع تسلسل JSON مع الاحتفاظ ببديل مكتبة Python القياسية.
- `msgspec`: تحليل typed للرسائل واستدعاءات الأدوات ذات العقود الثابتة.
- `uvloop`: حلقة أحداث اختيارية لـ CLI والبوابة، مع fallback إلى `asyncio`.
- حفظ الجلسات على دفعات لتقليل عمليات SQLite وI/O.
- تخفيف بدء التشغيل واكتشاف الأدوات باستخدام cache مُنسخ ومُبطل عند تغيّر الإعدادات.
- استخدام cache للبيانات الخارجية مع TTL وكتابة ذرية، دون أسرار.
- تنفيذ العمليات المستقلة بالتوازي مع ترتيب حتمي وحدود وtimeouts.

## المكاسب المتوقعة

تشير قياسات fork السابقة إلى 4–6x في JSON الكبير، و3–4x في مسار الرسائل، و19–38x في مسار حفظ الجلسات المُقاس، و2–4x في بدء التشغيل. هذه مراجع وليست ضمانات؛ يجب إعادة القياس في Hermes الفعلي.

يجب الحفاظ على prompt caching، توافق الإضافات والمهارات، fallback Python/`asyncio`، الأمان، وإمكانية التراجع. التفاصيل الكاملة في `README.md` و`SKILL.md`.
